# 먼저 묻고 시작

요청이 모호하면 코드를 쓰기 전에 아래를 **한 번에, 짧게** 묻는다. 이미 말한 것은 묻지 않는다.

1. 누가 쓰나 / 무엇을 하나 (주인공·목표)
2. 방해물이나 규칙
3. 끝났다고 볼 기준
4. 하지 말 것

답을 받으면 3줄 이내로 요약해 "이렇게 만들까요?"만 묻는다. 확인 전에는 만들지 않는다.
답은 짧게 한다.
