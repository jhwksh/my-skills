# 📮 homework-submit

과제를 GitHub에 올려 제출하기 전에, 빠뜨린 것을 AI가 한 번에 점검해 주는 스킬입니다.

## 왜 만들었나

과제를 낼 때마다 AI에게 같은 말을 반복하고 있었습니다.

| 매번 겪은 불편 | 실제로 있었던 일 |
|---|---|
| "푸시됐어? README 있어? 링크 열려?"를 매번 다시 물어봄 | 게임 과제와 Todo 과제에서 같은 확인을 두 번 시킴 |
| 제출란이 받는 링크 종류를 깜빡함 | 제출란은 `github.com`만 받는데 `github.io` 플레이 주소를 내려고 했음 |
| README의 "게임 열기"가 상대경로라 GitHub에서는 코드만 보임 | 눌러도 게임이 안 뜰 뻔했음 |
| 푸시 전에 키·`.env`가 올라갔는지 확인을 깜빡함 | — |
| 회고·마무리 문장까지 AI가 써 줄까 봐 걱정됨 | 내 경험이라 내가 써야 함 |

스킬이 하는 일은 이렇습니다. 매번 하던 확인을 순서대로 하고, 고치기 전에 허락을 받고, 제출할 링크 하나와 내가 직접 할 일 목록을 줍니다. 이제 "제출 점검해 줘" 한마디면 됩니다.

## 설치

적용할 프로젝트(제출할 과제 폴더)에 복사합니다.

```bash
# 이 저장소를 받은 뒤, 과제 프로젝트 루트에서
mkdir -p .claude/skills
cp -r <my-skills 경로>/.claude/skills/homework-submit .claude/skills/
```

## 호출

그 프로젝트를 연 상태에서 **새 대화**를 시작하고 이렇게 말합니다.

```
/homework-submit
```
또는 "과제 제출 점검해 줘"

## 확인한 결과

> ⚠️ 아래는 새 대화에서 직접 호출해 보고 채우세요. (해 보기 전에는 비워 둡니다)

- 적용 프로젝트: <예: HOMEWORK-PROJECT>
- 호출 문장: <예: /homework-submit>
- 나온 결과: <예: 푸시 상태, README 점검, 제출 링크 1개, 내가 할 일 목록>

## 포함하지 않는 것

인증 정보와 개인 데이터는 없습니다. 스킬은 읽기 점검부터 하고, README 수정·커밋·푸시는 사용자의 허락을 받은 뒤에만 합니다.
